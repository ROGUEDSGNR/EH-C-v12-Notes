# Lab Tasks Checklist: Scanning Networks

## Lab 1: Perform Host Discovery

### **Lab Scenario**

Identify active hosts in a target network to streamline further reconnaissance efforts.

### **Lab Objectives**

- Utilize Nmap for ARP, UDP, ICMP, and TCP scans.
- Perform host discovery using Angry IP Scanner.
- Document live systems within a specified IP range.

### **Lab Environment**

- Virtual Machines: Windows 11, Windows Server 2022, Windows Server 2019, Parrot Security, Ubuntu, Android
- Administrator privileges
- Internet connection

### **Checklist**

- [ ]  Set up all virtual machines.
- [ ]  Perform ARP scan with Nmap.
- [ ]  Conduct UDP ping scan with Nmap.
- [ ]  Execute ICMP echo ping and ping sweep.
- [ ]  Run Angry IP Scanner for host discovery.
- [ ]  Document results and analyze discovered hosts.
